** C++ Calculator **

A simple command-line calculator written in C++. It takes two numbers and performs a basic arithmetic operation.

** Features **
- Addition
- Subtraction
- Multiplication
- Division (with divide-by-zero check)
- Menu-driven using `switch`

** How to Run **

1. Clone or download this repository.
2. Compile the program:
   ```bash
   g++ calculator.cpp -o calculator
   ```
3. Run it:
   ```bash
   ./calculator
   ```
   On Windows, run `calculator.exe` instead.

** Example Output **


** Concepts Used **
- Input and output (`cin`, `cout`)
- Variables and data types (`double`, `int`)
